س1: ما هي القرارات التقنية التي اتخذتها في بناء بنية وتصميم واجهة المستخدم (Layout & UI Architecture)؟

اعتمدت على نظام المتغيرات المركزية CSS Variables في أعلى ملف التنسيقات لإدارة الألوان. هذه الإستراتيجية مكنتني من تبديل الثيم بالكامل إلى الوضع الليلي المظلم المريّح للعين (Dark Mode) بضغطة زر واحدة وعبر كلاس واحد body.dark دون تكرار الأكواد. لتصميم الهيكل، استخدمت واجهة الـ Grid لتقسيم الشاشة إلى عمودين متساويين ومتناسقين كالصورة المرجعية، مع استخدام خاصية position: fixed و flex-shrink: 0; لتثبيت شريط التنقل العلوي (Navbar) والفوتر في مكانهما، وعزل السكرول والتمرير داخل حاويات الكروت فقط لمنع اختفاء عناصر الفلترة العلوية.

س2: كيف قمتِ بتوظيف هياكل البيانات والخوارزميات (Data Structures) لتحسين الأداء؟

الـ Hash Set (في ميزة الحفظ): استخدمت كائن الـ Set من نوع TypeScript (Set<string>) لتخزين المعرفات (IDs) الخاصة بالفرص المحفوظة (savedOpportunityIds). اختيار الـ Set كان خياراً خوارزمياً ذكياً لأن عمليات التحقق (.has)، الإضافة (.add)، والحذف (.delete) تتم جميعها في زمن ثابت وبسرعة \(O(1)\)، مما يضمن أداءً فائق السرعة وفلترة فورية عند تفعيل زر "Saved only".الـ Array Filtering & Methods: لربط عدادات الفوتر حركياً وتفاعلياً، استخدمت دالة .reduce لحساب إجمالي الإعجابات، ودالة .filter لمعرفة عدد المنشورات والفرص المتقدم عليها تلقائياً من الـ State الحية بمجرد نقر الأزرار.


س3: ما هي أبرز التحديات التقنية (Challenges) التي واجهتكِ وكيف تغلبتِ عليها؟
 لابتوبي سيء عذبني كتير وعدت المشروع 3 مرات لان كان ينحذف وانتزع السيرفر ومابقا يزبط 
 واجهت مشكلة برمجية عند جلب بيانات قسم الفرص حيث كانت الصفحة تظل معلقة على حالة "Loading...". بعد تتبع المسار، اكتشفت وجود Bug (خطأ إملائي) في دالة الـ API بالـ Frontend، حيث كانت تقوم بتعديل State التحميل الخاص بقسم المجتمع بدلاً من قسم الفرص. قمت بإصلاحها وفصل الـ States لتعمل الكروت وتظهر فوراً.

 عند النزول لقراءة المنشورات، كانت أزرار الأقسام ومربعات البحث تصعد وتختفي للأعلى. قمت بحل هذا التحدي البصري برمجياً عبر إخراج حاويات الفلاتر بالكامل (community-filters-wrapper و opportunities-filters-wrapper) خارج حاويات الـ Scroll الحركية، مما جعل الفلاتر وأزرار "Liked only" و "Saved only" تثبت وتستقر في الأعلى بذكاء وتتحرك الكروت لوحدها بالأسفل.

 س4: ما هي الدروس المستفادة (Lessons Learned) من هذا التقييم؟

 تعلمت كيفية الربط الفعلي والمتزامن بين واجهات الفرونت إند (React) وسيرفر محلي (Node.js API) عبر طلبات الـ fetch واستخدام بروتوكولات الـ PATCH لتحديث جزئي ومباشر للبيانات (مثل زيادة الإعجابات أو حالة التقديم) دون الحاجة لإعادة تحميل كامل الصفحة، مما يعزز مهاراتي في بناء منتجات حقيقية واحترافية.
